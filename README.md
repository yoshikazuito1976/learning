# 高校生向け Python 体験授業教材

## 概要

このリポジトリは、**高校生向けの体験授業**として実施した「Pythonプログラミング入門」の教材です。  
Jupyter Notebook を使い、**コードを書きながら“対話的に”Pythonの基礎を体験する**ことを目的としています。

## 対象

- 高校生（プログラミング未経験者）
- Python に初めて触れる方
- 論理的思考やプログラミング的な発想を学びたい方

## 学習内容

この教材では、以下の基本文法を扱います：

- `print()` による出力
- 数値と文字列の操作
- 変数の利用
- 条件分岐（`if` 文）
- 繰り返し処理（`for` 文）

## 使用方法

1. [Anaconda](https://www.anaconda.com/) または Python＋Jupyter Notebook 環境を用意
2. このリポジトリをクローンまたは ZIP ダウンロード
3. `programing_first_step.ipynb` を開いて順番に実行
